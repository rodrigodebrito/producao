## Visão Geral

A identidade visual do TheraConnect foi desenvolvida para transmitir confiança, tranquilidade e profissionalismo. O design é minimalista mas acolhedor, utilizando gradientes suaves e elementos que remetem à conexão humana e bem-estar.

### Princípios de Design

- **Simplicidade**: Interfaces limpas e organizadas
- **Acessibilidade**: Design inclusivo para todos os usuários
- **Consistência**: Experiência coesa em toda a plataforma
- **Acolhimento**: Visual que transmite conforto e confiança

## Paleta de Cores

### Cores Principais

- **Azul Principal** (`#3E78B2`): Representa confiança, calma e profissionalismo
- **Verde-água** (`#7AB8BF`): Simboliza equilíbrio, bem-estar e tranquilidade
- **Coral/Acento** (`#FF6B6B`): Usado para elementos de destaque, representa energia e vivacidade

### Cores Semânticas

- **Sucesso** (`#4CAF50`): Para confirmações e ações bem-sucedidas
- **Aviso** (`#FF9800`): Para alertas e mensagens de atenção
- **Erro** (`#F44336`): Para erros e ações críticas

## Componentes

Os componentes são construídos a partir dos princípios e tokens definidos acima. Alguns dos principais componentes incluem:

### Botões

- **Primário**: Fundo azul principal, texto branco
- **Secundário**: Fundo verde-água, texto branco
- **Outline**: Borda azul principal, texto azul principal
- **Desabilitado**: Opacidade reduzida, não clicável

### Cards

- Fundo branco
- Bordas arredondadas
- Sombra suave
- Diferentes níveis de elevação

### Formulários

- Inputs com bordas leves
- Feedback visual para estados (foco, erro, sucesso)
- Labels claros e mensagens de ajuda

## Iconografia

A TheraConnect utiliza a biblioteca Feather Icons para manter uma linguagem visual consistente em toda a plataforma.

Exemplos de uso:
- Navegação: `home`, `calendar`, `settings`
- Ações: `edit`, `trash`, `save`
- Notificações: `bell`, `alert-circle`, `check-circle`

## Ilustrações

As ilustrações são vetoriais (SVG) e seguem as seguintes características:
- Estilo minimalista e moderno
- Uso de gradientes suaves nas cores da marca
- Formas orgânicas e arredondadas
- Representam conexão, bem-estar e terapia
